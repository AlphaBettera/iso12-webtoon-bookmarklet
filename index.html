条漫逐屏翻页 · 书签一键复制

把老 iPad / iPhone 的 Safari 变成「点一下翻一屏」的条漫阅读器。

V2.1 全屏可滑动版 · 17.5/65/17.5 分区 · iPad mini 2 / iOS 12.5.8 · 需 Safari 本体 · 无需越狱

执行顺序：步骤1 → 步骤2（→ 步骤3 备用）
日常只用前两步即可。下方点按钮复制代码，再到 Safari 书签列表里编辑粘贴。

1 宽度适配

逐层拆掉祖先容器写死的宽度，解决画面右移/留白；图片铺满视口。MutationObserver 让懒加载追加的图片自动适配。

2 逐屏翻页（核心）

轻点下侧 17.5% 前进、上侧 17.5% 回看；滑动（位移 >15px）一律放行原生滚动，全屏下也能调整位置。每次翻页同时写 mgy 和 mgr。替换代码后请刷新页面重走步骤1 → 步骤2。

3 全屏 + 位置比例同步（备用）

画面最大；进、出全屏按 mgr 比例停在同一画面，滑动期间暂停拉回避免位置回弹。Safari 进全屏会清零滚动并重排布局，所以不用绝对像素。必须最后点。

附：清空位置记录

想从头看时先点这个极短书签，再走完整流程。

创建书签的方法：Safari 打开任意网页 → 分享 →「添加书签」→ 直接保存 → 点书签图标 →「编辑」→ 点进 URL 字段全选删除 → 粘贴代码 →「完成」→ 再进编辑确认开头是 javascript:。

真全屏的坑：步骤3 下点页脚菜单会卡死（iOS 12 系统层 bug）；滑动已在 V2.1 支持。日常推荐只用步骤1 + 步骤2。

夸克等第三方浏览器：步骤1、2 或有戏，步骤3 的全屏 API 大概率无效（WKWebView 不暴露），能否执行 javascript: 书签需实测。
